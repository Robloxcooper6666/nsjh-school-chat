探索 NSJH LIVE 的核心

了解我們如何透過現代 Web 技術，建立起一個秒級延遲、隱私安全且充滿互動性的校園交流平台。

即時通訊原理

基於 Pub/Sub (發布/訂閱) 模型。當你點擊發送，資料會透過 WebSocket 長連接瞬間推送至 Ably 雲端節點，並在全球各地的訂閱者端同步更新 DOM，無需重整頁面。

動態主題技術

利用 CSS 自定義屬性 (Variables) 與 JavaScript 的 Class 切換。當偵測到特殊訊息（如 67 模式）時，系統會動態改寫 document.body 的類名，達成秒級的全屏視覺變換。

隱私與安全

我們採用 匿名化身分驗證。訊息傳輸過程中經過 TLS 加密，且伺服器端不儲存長期的用戶識別資料，僅在本地 LocalStorage 保留您的偏好設定，確保交流隱私。

常見問答 FAQ

Q: 為什麼看板有時候會突然變色？

這是看板的「互動同步功能」。當發文者選擇了特別主題（如 67 模式或 Gay Power）時，該效果會透過資料雲同步給所有正在看版的同學，維持 5 秒後自動恢復，讓交流更具動感。

Q: 遺失歷史訊息怎麼辦？

本看板主要為「即時交流」設計。目前會自動保留最近的 50 則訊息於您的瀏覽器快取中。如果您清除了瀏覽器資料，歷史訊息將會重置。

Q: 如何參與開發？

本專案程式碼託管於 GitHub。如果你懂 HTML/JS，歡迎提交 Pull Request；或者提供你想要的「新模式」點子給我們！
